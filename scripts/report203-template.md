## 7. The checks of §3

### 7.1 Kernel replay (`scripts/Replay.lean`, output `doc/depcensus/replay.txt`)

The script imports `Lean` only. It reads the constants of the 863 library modules from their
`.olean` files without importing them, computes the raw closure of the two targets again (a
third computation, from the `.olean` data rather than from the census files), builds an
environment by `importModules` of the 690 external modules of `external-modules.tsv` (no `HPC`
module), and calls `Lean.Environment.replay` with the 12480 library constants of the closure.

```
{{replay}}
```

So: the closure is complete (every external constant it needs is in the imported Mathlib, `Init`
and Batteries modules, and nothing else of the library is needed); **every one of the 12480
constants is accepted by the kernel**, in about two minutes; the two targets are present after the
replay, as theorems, with the stored types; and the statements of `HPC/BJ59/BJ59E.lean`, copied
verbatim from the file and elaborated in the replayed environment, give exactly the replayed
types (`Expr` equality). The replay skips unsafe and partial constants; there are none in the
closure.

### 7.2 Second computation (`scripts/closure.py`, output `doc/depcensus/closure-check.txt`)

The script reads only `nodes.tsv`, `edges.tsv`, `edges-external.tsv` (and, for the comparison,
the census outputs), recomputes the closure by breadth-first search, applies the used rule of
§2.2, counts each file's lines itself, extends ranges over docstrings by its own scan of the files,
and recomputes `used.txt`, the four counts of every row of `modules.tsv`, the counts of
`external.tsv`, every row of `summary.tsv` (primary and comparison targets) and the `dependents`
column of `spine.tsv`; it also checks that the spine order is a dependency order.

```
{{closurecheck}}
```

**Agreement in every number** (0 differences). A first run found 32 differences in the covered
lines; the cause was the script's own docstring scan, which crossed a `/-! … -/` module comment and
reached the docstring of an earlier declaration. Both programs now accept only a comment opened by
`/--`; the census numbers did not change.

Numbers that rest on one computation only:

* the node attributes in `nodes.tsv`: kind, declaration (the owner of an auxiliary constant),
  counted, headline, declaration ranges; and the edges themselves (both the census and the
  second computation use the census's `nodes.tsv` and edge files; the replay recomputes the
  closure from the `.olean` files and agrees with `closure.tsv`, which checks the edges of the
  closure but not the attributes);
* `import-only.txt` (the import closure of the used modules);
* the package and module of each external constant (the second computation checks the counts,
  not the attribution);
* the spine order itself (the second computation checks that it is a dependency order and
  recomputes the dependents, but takes the order from `spine.tsv`);
* the grouping by paper of §5 (Table 5) and the per-directory descriptions of §3;
* the sanity checks of §2.4 (`sanity.tsv`; the membership of the eight names is visible in
  `closure.tsv`, which the replay confirms).
