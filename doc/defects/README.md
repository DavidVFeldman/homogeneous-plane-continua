# Defects in the published proofs

Two documents record what the formalization found wrong in the published sources it follows.

* `DEFECTS-LEDGER.md`: the defects ledger, ordered by source (paper by paper), with the full
  entry for each defect.
* `defects-by-severity.tex` and `defects-by-severity.pdf`: the same defects ordered by severity,
  most serious first. Its Appendix B lists every Lean name the document cites.

Counts: 23 printed statements are false, and 18 printed proofs are defective while the statement
is true.

Both documents cite Lean declaration names and file paths of this repository.
