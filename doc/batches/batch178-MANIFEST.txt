How the file list was made
--------------------------
The request asked for the files from `git diff --name-status` against the
batch-177 commit. This repository's git history has only one commit
("Initial commit"), with no tag or branch for batch 177, so that diff cannot
be run. The list below was put together from the batch-178 report instead
(doc/batches/REPORT-batch178.md, "Files", "Earlier files edited" and
"The uploads"), plus the files that mention the new batch-178 modules.
Status letters follow the --name-status convention (A = added, M = modified)
and are inferred, not taken from git.
